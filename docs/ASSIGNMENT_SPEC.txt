১. Project Overview
SIS Cyber Fortress একটি সমন্বিত Cybersecurity Ecosystem। এর লক্ষ্য হলো Android App, Web Application, Backend API, Database এবং Super Admin Dashboard-এর মাধ্যমে ১২টি আলাদা Security Module একটি কেন্দ্রীয় প্ল্যাটফর্মে যুক্ত করা। শিক্ষার্থীরা দলগতভাবে নির্ধারিত Module তৈরি করবে এবং শেষে সব Module কেন্দ্রীয় Dashboard-এর সঙ্গে Integration করবে।
২. Project Objectives
বাস্তব Software Development Lifecycle অনুসরণ করে একটি কার্যকর Product তৈরি করা।
Android ও Web Application Development-এর বাস্তব অভিজ্ঞতা অর্জন করা।
Secure Authentication, Role-Based Access Control (RBAC), API ও Database Integration শেখা।
১২টি Cybersecurity Module আলাদাভাবে তৈরি করে একটি Unified Platform-এ যুক্ত করা।
Git/GitHub, Documentation, Testing, Presentation ও Team Collaboration অনুশীলন করা।
শুধু অনুমোদিত ডিভাইস, ওয়েবসাইট, নেটওয়ার্ক ও ডেটায় নিরাপদ পরীক্ষা করা।
৩. ১২টি Development Module
01. SIS Identity Guardian
Digital identity ও account protection।
Secure login ও MFA/Passkey interface
Login activity ও suspicious sign-in alert
Account security status dashboard
অনুমোদিত breach-data service দিয়ে compromised credential alert; plaintext password সংগ্রহ নয়
02. SIS Phishing Shield
Phishing, scam ও malicious link শনাক্তকরণ।
URL/link scanner ও risk result
Suspicious domain warning
Threat report submission
Reputation feed/API integration ও false-positive handling
03. SIS Endpoint Guardian
Android endpoint/device security monitoring।
Device registration ও inventory
Installed app inventory (Android policy অনুযায়ী)
App permission overview
Security posture ও compliance dashboard
04. SIS Network Sentinel
Wi-Fi ও network security awareness।
বর্তমান network information (অনুমতি ও OS সীমা অনুযায়ী)
Open/unsafe Wi-Fi warning
Network security checklist
Dashboard-এ device network risk summary
05. SIS Vault Guardian
Encrypted password, note ও document vault।
Encrypted vault ও secure notes
Biometric/PIN unlock
Client-side encryption এবং secure key handling
Vault recovery design; Admin যেন vault-এর plaintext দেখতে না পারে
06. SIS Ransomware Guardian
Ransomware risk awareness ও data recovery readiness।
Backup status ও recovery readiness
Suspicious file-change indicator যেখানে বৈধভাবে সম্ভব
Incident alert ও response checklist
নিরাপদ backup verification; বাস্তব ransomware চালানো যাবে না
07. SIS WebShield
অনুমোদিত ওয়েবসাইটের security scanning ও monitoring।
SSL/TLS certificate status
DNS ও security header checks
Safe configuration checks
Authorized scope-এর vulnerability scan ও remediation report
08. SIS Digital Forensics
Security incident evidence ও case management।
Incident/case creation
Evidence metadata ও chain-of-custody log
Timeline ও event correlation
Evidence access control এবং export report
09. SIS Access Guardian
Authentication ও access management।
MFA ও Passkey support
Session/device management
Role ও permission management
Login history এবং suspicious access alerts
10. SIS Threat Intelligence
Cyber threat feed ও indicator management।
Trusted threat feed integration
IOC management: domain, URL, IP, hash
Threat tagging ও severity
Threat search, report ও source attribution
11. SIS Cloud Backup Guardian
Encrypted backup ও recovery management।
Backup scheduling ও status
Encrypted file backup
Restore workflow ও integrity check
Storage usage, retention ও recovery report
12. SIS Cyber SOC
Centralized Security Operations Center।
Unified alert dashboard
Incident severity ও prioritization
Incident assignment ও status workflow
Module-wise analytics, audit trail ও SOC reports
৪. Central Super Admin Dashboard – Core Team Task
একটি Core Team সব ১২টি Module-এর জন্য কেন্দ্রীয় Web Dashboard তৈরি ও পরিচালনা করবে।
Secure Admin Login, MFA এবং session management।
Multiple Authorized Administrators: Super Admin, Security Admin, Module Admin এবং Auditor role।
User Management ও role/permission assignment।
১২টি Module-এর overview, navigation ও status।
Device Management, website/project inventory এবং authorized asset registry।
Security Alerts, Incident Management ও notification center।
Audit Logs: কে, কখন, কোন action করেছে তার record।
Reports &amp; Analytics: module status, incidents, scan results ও trends।
System Settings, API health, integration status এবং backup status।
সব dashboard data বাস্তব backend/API থেকে আসবে; hardcoded fake statistics ব্যবহার করা যাবে না।

৭. Integration Requirements
প্রতিটি Module-এর নিজস্ব feature boundary, API contract ও database ownership/documentation থাকতে হবে।
Shared Authentication, RBAC, audit logging, notification ও user management ব্যবহার করতে হবে।
প্রতিটি API-তে authentication, authorization, input validation ও error handling থাকতে হবে।
Module-এর data অন্য Module-এ পাঠানোর আগে প্রয়োজন ও permission যাচাই করতে হবে।
একটি Module-এর security failure যেন অন্য Module-এ অননুমোদিত access না দেয়।
সব Module-এর status, alerts ও reports Super Admin Dashboard-এ দেখা যাবে।
Integration-এর জন্য API documentation এবং test collection জমা দিতে হবে।
৮. Security, Privacy ও Ethical Rules
শুধু নিজের বা লিখিত অনুমতি পাওয়া ডিভাইস, ওয়েবসাইট, নেটওয়ার্ক ও অ্যাকাউন্টে পরীক্ষা করা যাবে।
কোনো unauthorized access, credential theft, stealth surveillance বা data exfiltration করা যাবে না।
Android-এর permission, Device Owner, OEM বা Bootloader capability জোর করে bypass করা যাবে না।
অ্যাপের capability Android version, manufacturer ও permission অনুযায়ী ভিন্ন হতে পারে; unsupported feature স্পষ্টভাবে দেখাতে হবে।
কোনো fake security status, fake scan result বা ভুয়া test pass দেখানো যাবে না।
Password, private key, biometric data বা secret plaintext আকারে সংরক্ষণ করা যাবে না।
Vault-এর plaintext content Super Admin বা অন্য Module-এর কাছে প্রকাশ করা যাবে না।
Location, file access ও device monitoring-এর জন্য user consent ও প্রয়োজনীয় disclosure থাকতে হবে।
Remote wipe বা destructive operation এই assignment-এর default scope নয়; ভবিষ্যতে যোগ হলে explicit authorization ও confirmation আবশ্যক।
Security testing হবে safe test data, lab environment এবং অনুমোদিত scope-এ।
